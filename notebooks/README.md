# notebooks

Numbered exploration notebooks: `NN_topic.ipynb` (e.g. `01_claims_eda.ipynb`).

Conventions: restart-and-run-all before committing; imports from `oscar_cs` instead of
copy-pasted loaders; anything load-bearing (a cleaning step, a feature definition)
graduates to `src/` or `scripts/` the second time it's needed. Figures that go in a
report are saved to `reports/figures/` by code, not screenshotted.
