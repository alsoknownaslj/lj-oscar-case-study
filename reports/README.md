# reports

The deliverables. One markdown file per write-up: `YYYY-MM-DD_slug.md`, figures in
`figures/` named `YYYY-MM-DD_slug_fig01.png`.

Shape: skeleton in `CLAUDE.md` → "Reports"; detail + Lauren's preferences in
`references/report-style.md`. Every report gets a `humanize` pass before it's done, and
every number in it must be reproducible from a committed script or notebook.
